# W-Tech Wireless Security Scanner — Site de présentation

Site vitrine statique en HTML, CSS et JavaScript, style **Blue Minimal**.

## Fichiers
- `index.html` : structure et contenu du site.
- `style.css` : styles et responsive design.
- `script.js` : menu mobile, animations au défilement, galerie et bouton retour en haut.
- `images/` : emplacement des photos et captures du projet.

## Lancer le site
Ouvrir `index.html` dans un navigateur. Pour un serveur local simple, depuis ce dossier :
```bash
python3 -m http.server 8000
```
Puis ouvrir `http://localhost:8000`.

## Images à ajouter
Copier tes propres photos dans `images/` en utilisant les noms suivants :
- `esp32.jpg`
- `usb-cable.jpg`
- `ubuntu.jpg`
- `realisation-1.jpg`
- `serial-wifi.jpg`
- `serial-ble.jpg`
- `serial-demo.jpg`

Les emplacements restent visuellement identifiables si les images ne sont pas encore présentes.

## Personnalisation
- Modifier les textes directement dans `index.html`.
- Modifier les couleurs dans les variables CSS au début de `style.css`.
- Le lien GitHub du pied de page pointe actuellement vers `https://github.com/lelackwarren-ui`.
